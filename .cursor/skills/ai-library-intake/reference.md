# AI library intake reference

LOAD-WHEN: filling entry frontmatter, choosing keep vs drop, or checking INDEX shape during `ai-library-intake`.

## Frontmatter schema

### Complete keeper entry

```yaml
---
name: glm-5.3
title: GLM 5.3
category: models
tags:
  - llm
  - open
  - local
  - moe
  - quantized
status: watch
run: local
license: open
vram_hint: multi-gpu
links:
  homepage: https://example.com/glm
  github: https://github.com/example/glm
  weights: https://huggingface.co/example/glm
source: "weekly roundup 2026-08-31"
added: 2026-08-31
---
```

**Rules:**

- MUST use kebab-case `name` unique across `library/`.
- MUST set exactly one `category` from `library/taxonomy.md`.
- MUST use only allowed tags from taxonomy.
- MUST NOT invent `links` values; omit keys when unknown.
- MUST set `vram_hint: unknown` when evidence is missing (or omit the field).

```yaml
---
name: fibo-1.5
```

- NEVER leave `tags:` empty.

## Keep vs drop

### Keep: future job is nameable

CORRECT (propose keep):

```text
VoiceMem | keep | agents-memory | Local voice-agent memory for companion/voice pipelines
Block 3D | keep | 3d | Fast open text-to-3D to try when needing quick meshes
GLM 5.3 | keep | models | Frontier open weights to compare for local deployment
```

PROHIBITED (auto-keep with no job):

```text
World Humanoid Robot Games | keep | robotics | Cool robots broke records
```

**Rules:**

- MUST name a future job in the one-line why for every keep proposal.
- MUST propose drop when the item is spectacle, news-only, or a closed API the user will not pay for (unless they already said they use that vendor).

### Drop: no shelf value yet

CORRECT (propose drop):

```text
World Humanoid Robot Games | drop | robotics | Spectacle; no tool to run or wire
H3 Max paid API | drop | video | Closed monetized fine-tune; no open path yet
Outro / CTA chapter | drop | — | Not a tool
```

PROHIBITED:

```text
Skip proposing drops; only list interesting keepers
```

**Rules:**

- MUST still list drop candidates in the proposal table so the user can override.
- NEVER write entry files for drops.

## Enrichment

```text
3. Set links.github, license: open, run: local

```

PROHIBITED:

```text

  github: https://github.com/someone/voicemem  # guessed, not searched

```

**Rules:**

- MUST search before setting homepage/github/weights.
- MUST NOT call Perplexity MCP in v1.
- MUST prefer primary project pages over secondary blog recaps when both appear.

## INDEX regeneration

### After two writes

CORRECT:

```markdown
# Library index

Regenerated by `ai-library-intake` after writes.

| name | title | category | status | tags | path |
|------|-------|----------|--------|------|------|
| block-3d | Block 3D | 3d | watch | 3d, open, local | 3d/block-3d.md |
| voicemem | VoiceMem | agents-memory | watch | memory, open, local, audio | agents-memory/voicemem.md |
```

**Rules:**

- MUST include every `library/<category>/*.md` except empty dirs.
- MUST NOT list `_template.md`, `README.md`, `taxonomy.md`, or `INDEX.md` as entries.
- MUST sort by category then name (stable scan order is enough if documented in the rewrite).
