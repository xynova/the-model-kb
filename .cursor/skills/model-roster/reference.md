## Kind decision

| Situation | kind |
|-----------|------|
| Open weights, any host you can leave | `sovereign` |
| Lab-locked API (direct or proxied) | `provider` |
| Product-bundled (Cursor, …) | `service` |

CORRECT: `@cf/meta/...` → sovereign + runtime cloudflare  
CORRECT: Claude through CF gateway → provider + lab anthropic  
CORRECT: Cursor model picker id → service + service cursor  
PROHIBITED: labeling open `@cf/...` as provider  
PROHIBITED: labeling Cursor as sovereign  

## Keep vs drop

### Same-segment peers

CORRECT (peer: same weights, other host):

```text
[2/3] gemma-4-26b-a4b-deepinfra | sovereign | multimodal | peer

Same open Gemma 4 26B-A4B on DeepInfra. Host-price compare vs CF.
keep? y/n
```

CORRECT (baseline, not peer):

```text
[3/3] qwen3-30b-a3b-cf | sovereign | general | baseline

Older Qwen3 MoE on CF. Not a Gemma 4 peer; optional cheap baseline.
keep? y/n
```

PROHIBITED: labeling an older/weaker cut as “same segment” without saying baseline.

### Interactive one-at-a-time gate

CORRECT:

```text
[1/2] llama-3.2-3b-cf | sovereign | general

Meta Llama 3.2 3B on Cloudflare Workers AI. Portable open weights; switch to DeepInfra or local anytime. Use when you want a cheap small chat model on CF.

keep? y/n
```

PROHIBITED: fluffy hype; batch keep sets; writing before `y`.
