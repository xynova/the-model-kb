Weekly batches of library keepers, grouped by each entry's `added` ISO week. Each week file lists additions under a heading per category section.

The current ISO week is open; earlier weeks are closed. Refresh after keeps with:

```bash
cd tools/library-intake
go run ./cmd/library-intake index refresh --library ../../library
```
