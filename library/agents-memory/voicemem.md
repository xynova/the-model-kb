# VoiceMem

## What it is

Open memory layer for voice assistants: facts in one store, personality and emotion in another, built for low-latency streaming use (Apache-2.0).

## Why keep

Wire into companion or duplex voice pipelines when the agent must remember people across sessions without stuffing full transcripts into context.

## When to reach for it

Building or evaluating real-time voice agents that need personal memory.

## Caveats

Local demos pull extra models from Hugging Face. Confirm setup cost for your stack (API keys, ASR, embeddings).
