# AI tools library

Curated shelf of AI tools and systems to revisit when there is time and a real need. Not a news archive.

## Layout

| Path | Role |
|------|------|
| [taxonomy.md](taxonomy.md) | Categories, allowed tags, keep criteria |
| [_template.md](_template.md) | Entry frontmatter and body skeleton |
| [INDEX.md](INDEX.md) | Flat list of all entries (regenerated by intake) |
| `<category>/` | One markdown file per kept item |

## How to browse

- Scan [INDEX.md](INDEX.md) for name, category, status, and tags.
- Filter with ripgrep on frontmatter, for example:

```bash
rg -l 'status: reach-for' library/
rg -l 'tags:' -A 6 library/ | rg 'local'
rg '^name: ' library/**/*.md
```

## How to add

1. Prefer the project skill `ai-library-intake` with a roundup or notes dump (keep/drop gate, WebSearch enrichment, INDEX refresh).
2. Manual: copy [_template.md](_template.md), place under the right category, fill fields from [taxonomy.md](taxonomy.md), then refresh INDEX or re-run intake.

## Keep rule

Keep only if you can name a future job (local run, pipeline wire-up, or model/tool comparison). Drop spectacle and dead-end closed APIs.
